# Aula 01 — Organização de Projetos no RStudio

**Playlist:** Transcriptoma de Célula Única  
**Canal:** Seif Bioinformatics

## Objetivos da aula

- Criar um projeto `.Rproj` no RStudio.
- Separar dados, scripts, funções e resultados.
- Utilizar caminhos relativos e arquivos `.qmd` do Quarto.
- Reutilizar funções com `source()`.
- Salvar objetos e figuras para evitar reprocessamento.

## Arquivos

- [`organizacao_projeto.R`](organizacao_projeto.R): script **demonstrativo** de organização de pastas e carregamento de funções; não é uma transcrição integral do código da gravação.

## Como executar

Crie/abra um RStudio Project. Execute os comandos a partir da pasta raiz do projeto. Ajuste os caminhos para os arquivos que você realmente possui.
