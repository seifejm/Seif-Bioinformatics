# Seif Bioinformatics 🧬

**Da Biologia aos Dados**

Repositório oficial de materiais complementares das videoaulas do canal **Seif Bioinformatics** no YouTube.

Aqui você encontra scripts em R e Python, explicações, exemplos e referências associados às aulas de bioinformática, transcriptômica de célula única, acessibilidade da cromatina, biologia molecular e bioestatística.

## Conteúdos

| Tema | Pasta |
|---|---|
| Transcriptômica de célula única (scRNA-seq) | [`01-sc_RNA-seq/`](01-sc_RNA-seq/) |
| scATAC-seq e acessibilidade da cromatina | [`02-sc_atac-seq/`](02-sc_atac-seq/) |
| Bioestatística e modelagem | [`03-bioestatistica/`](03-bioestatistica/) |
| Biologia molecular | [`04-biologia-molecular/`](04-biologia-molecular/) |
| R e Python para biologia | [`05-r-python/`](05-r-python/) |

## Como usar

1. Acesse a pasta correspondente ao tema e à aula.
2. Leia o `README.md` da aula antes de executar os códigos.
3. Confira os requisitos e versões dos pacotes.
4. Baixe os dados originais dos links indicados na aula, quando aplicável.

> Os scripts são recursos didáticos. Adapte filtros e parâmetros ao seu próprio desenho experimental. Dados reais de participantes e resultados confidenciais não devem ser publicados.
